# Website assets

The city, French desk, objects, textures and framework figures use original procedural geometry, canvas drawings and SVG. No Cities: Skylines game assets are included.

The nine illustrated scenes were generated with the built-in imagegen tool for this project. Generation prompts and source provenance are saved in the project source; no film stills or existing animation frames are included.

Instrument Serif and Noto Serif SC: SIL OFL; licenses are included beside the bundled local fonts. https://github.com/google/fonts/tree/main/ofl/instrumentserif and https://github.com/google/fonts/tree/main/ofl/notoserifsc .

Three.js 0.187.0: https://github.com/mrdoob/three.js — MIT, included in three-LICENSE.txt.

Manrope: https://github.com/google/fonts/tree/main/ofl/manrope — SIL OFL, included in fonts/OFL.txt.

Noto Sans SC: https://github.com/google/fonts/tree/main/ofl/notosanssc — SIL OFL, included in fonts/NotoSansSC-OFL.txt. A local glyph subset is bundled.

Phosphor regular navigation icons: https://github.com/phosphor-icons/core — MIT, included in icons/LICENSE.
